# 🎮 GodWiki

Wiki sobre o universo de **God of War** desenvolvida durante o curso **HTML Web Developer** na DIO.

## 📌 Descrição

Projeto com múltiplas páginas simulando uma wiki real, cobrindo personagens, armas e artefatos do universo de God of War.

## ⚙️ Páginas

- **index.html** — Página principal
- **deus-da-guerra.html** — Informações sobre o jogo
- **armas.html** — Armas e Artefatos
