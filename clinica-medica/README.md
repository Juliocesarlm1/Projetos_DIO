# 🏥 Clínica Médica

Site de clínica médica desenvolvido durante o curso **HTML Web Developer** na DIO.

## 📌 Descrição

Projeto com múltiplas páginas simulando um site real de clínica médica.

## ⚙️ Páginas

- **index.html** — Página principal
- **sobre.html** — Sobre a clínica
- **contato.html** — Contato
- **horarios.html** — Horários de atendimento
